# 업무포털 자동화 도우미 (나이스 · 에듀파인)

교사의 관찰과 입력을 바탕으로 나이스·에듀파인 문서의 **초안**을 만드는 Streamlit 웹앱입니다.
기존 GPTs 지침을 단계별 화면으로 옮겼습니다.

| 업무포털 | 작성기 | 진행 단계 |
|---|---|---|
| 나이스 | 행발 · 창체(자율/동아리) · 세특 | 자료 입력 → 분석 → 교사 피드백 → 최종 작성 |
| 에듀파인 | 기안 · 품의 | 제목 입력(예시 자동 선택) → 작성 → 확인·수정 |

## 주요 기능
- 나이스 바이트 실시간 계산 (2024 기재요령 기준: 한글 3, 영문·숫자·공백 1, 엔터 1바이트)과 분량 초과 시 자동 축약
- 학생 이름 자동 치환 (AI에 보내기 전에 '학생'으로 바꿈), 결과에 이름이 남으면 경고
- 기재 금지 표현 자동 점검 (공인어학시험, 대학명, 수상, 대회, 논문, 특허, 장학금, 방과후 등)
- 세특: 과목명으로 교육부 2024 교과 세특 기재 예시(초·중·고 160개 + 전문교과 13개) 중 같은 과목 예시를 자동 참고
- 기안·품의: 제목의 단어('제출', '협의회', '구입', '지급' 등)로 예시문 자동 선택, '관련' 줄 고정, 모르는 정보는 '○○'로 비움
- 기본 자료 내장 + 교사 개인 자료 업로드(선택): txt, md, pdf, docx, hwpx
- 체험 모드: API 키 없이 화면 흐름 확인

## 폴더 구조
```
upmu-portal/
├─ app.py                  # 첫 화면: 나이스 / 에듀파인 / 도구 선택
├─ core/                   # 공통 부품 (AI 호출, 글자 수 계산, 자료 읽기, 화면 부품)
├─ engines/
│  ├─ record_engine.py     # 나이스(생기부형) 진행 엔진
│  ├─ document_engine.py   # 에듀파인(공문형) 진행 엔진
│  └─ tools.py             # 사용 안내, 참고 자료실, 기본 자료 점검
├─ writers/                # 작성기별 설정 (안내 문구, 입력 칸, 규칙, 분량, 자료 경로)
└─ resources/              # 기본 자료
   ├─ neis/                # 예시문, 참고 예시, 작성요령 요약
   ├─ edufine/             # 기안·품의 예시문, 작성요령
   └─ originals/           # 원본 PDF (열람·내려받기용, AI에 보내지 않음)
```

## 내 PC에서 실행 (VS Code 터미널)
```bash
cd upmu-portal
python -m venv venv
venv\Scripts\activate            # 맥: source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
API 키를 매번 입력하기 번거로우면 `.streamlit/secrets.toml.example`을 `secrets.toml`로 복사해 키를 넣으세요. (개인 PC 전용)

## Streamlit Community Cloud 배포
1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올립니다. (`.gitignore`가 `secrets.toml`을 막아 줍니다)
2. share.streamlit.io에 GitHub 계정으로 로그인 → **Create app** → 저장소, 브랜치, `app.py` 선택 → Deploy
3. 앱 이름(주소)을 정합니다. 예: `upmu-portal.streamlit.app`

⚠️ **배포한 앱의 Settings → Secrets에 API 키를 넣지 마세요.** 넣으면 모든 사용자가 운영자의 키로 쓰게 됩니다.
교사들은 각자 사이드바에 본인 키를 입력합니다.

## 기본 자료 바꾸기
- `resources/neis/*_예시문.txt`: 교사 톤앤매너 예시. `## 예시문 N` 머리로 구분합니다.
- `resources/edufine/*_예시문.txt`: `## CaseN: ... '단어' ...` 형식. 작은따옴표 안 단어가 제목에 있으면 그 예시를 씁니다.
- `*_작성요령.txt`: 작성기에 적용되는 규칙 요약본. 매년 기재요령이 바뀌면 이 파일을 고칩니다.
- 파일을 고쳐 GitHub에 올리면 배포 앱에 바로 반영됩니다. 앱의 **도구 → 기본 자료 점검**에서 제대로 읽히는지 확인하세요.

## 새 작성기 추가
`writers/` 에 설정 파일을 하나 만들고(기존 파일 복사 후 수정) `writers/__init__.py`의 `WRITERS`, `MENU`에 한 줄씩 추가합니다.
예: 진로활동 특기사항(700자) — 엔진 코드는 고칠 필요가 없습니다.

## 모델
사이드바에서 OpenAI(gpt-5.6-terra 등) 또는 Claude(claude-sonnet-5-5 등)를 고릅니다.
목록에 없는 모델은 '직접 입력'으로 이름을 넣으면 됩니다. 모델 이름은 각 회사 문서에서 확인하세요.

## 개인정보와 책임
- 입력 내용은 선택한 AI 회사의 API로만 전송되며, 이 앱은 아무것도 저장하지 않습니다.
- 공개 저장소에 올라가는 기본 자료에는 실제 학생 문장, 학교명, 실명을 넣지 마세요.
- AI 결과는 초안입니다. 사실 여부와 기재요령 준수를 확인하고, 최종 기재 책임은 교사에게 있습니다.
